# OCR PT 1年次 成績＆期末目標点シミュレーター Pro

シラバス原文の評価比率（前期試験・後期試験・小テスト・プレテスト・Web宿題・実習レポート・実技等）に基づき、目標総合点（60点/70点/80点/90点）に到達するために**「後期末筆記試験で何点取る必要があるか」**を自動逆算するWebシミュレーターです。

## 主な機能
- **目標グレード即時切替**: 60点（合格ライン）、70点（良/B）、80点（優/A）、90点（秀/S）
- **通年科目・複合評価科目**: 持ち点・スライダー操作によるリアルタイム必要点シミュレーション
- **筆記100%科目一覧**: 素点がそのまま成績になる科目の基準点表示
- **実技・課題100%科目一覧**: 定期筆記試験のない実習・ゼミ科目の評価基準表示
- **ローカルストレージ自動保存**: 入力値の保持・初期化
